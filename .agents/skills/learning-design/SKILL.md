# Learning Design Skill
Use Learn → Note → Practice → Verify → Review. Every topic needs an observable outcome. Notes should include: why it matters, mental model, concepts, commands, worked example, pitfalls, practice, recall questions, five-line summary. Mastery: 0 not started; 1 seen; 2 can follow; 3 can do with reference; 4 unaided; 5 explain/troubleshoot.
