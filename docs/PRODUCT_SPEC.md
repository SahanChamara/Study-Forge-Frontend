# StudyForge Product Specification

## Problem
Self-study fails because learners often do not know where to start, what order to follow, what “done” means, how to practice, or how to keep notes useful. StudyForge turns a technology into an executable personal curriculum.

## Target user
A software/DevOps engineer independently learning Linux, networking, Docker, Kubernetes, cloud, Terraform, CI/CD, databases, observability, security, languages, etc.

## Core jobs
- Give me a clear path from beginner to job-ready depth.
- Tell me what to learn next and why.
- Keep notes concise and structured.
- Make me practice instead of only consume content.
- Show what I can actually do without help.
- Help me revisit weak areas.

## MVP
Authentication; learning paths; ordered modules/topics; Linux Basic→Advanced seed; explicit objectives/prerequisites/status/mastery; Markdown smart notes; practice tasks/labs; simple progress dashboard.

## Not MVP
File uploads, community/team features, automatic scraping, automatic AI without review, paid-service dependencies.

## Success question set
The user can always answer: What next? What outcome? What did I learn? What practice proves it? What should I review?

## Non-functional
UID-isolated data; TypeScript; mobile-responsive; no frontend service secrets; efficient enough for personal Firestore free quota; agent changes build/test verified before phase completion.
