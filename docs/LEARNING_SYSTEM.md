# Learning System

## L-N-P-V-R
**Learn → Note → Practice → Verify → Review**

### Mastery scale
0 Not started; 1 Seen; 2 Can follow; 3 Can do with reference; 4 Can do unaided; 5 Can explain/troubleshoot.

### Smart note template
```md
# <Topic>
## Why this matters
## Mental model
## Key concepts
## Commands / syntax
## Worked example
## Pitfalls / debugging
## Practice I completed
## Recall questions
## 5-line summary
```

### Default session shape
5m outcome/recall → 20m learn → 10m note from memory → 20m hands-on → 5m verify/next step.

### Linux progression
Foundations → text/files → users/permissions → processes/packages → Bash automation → storage → networking/SSH → systemd/logs/boot → security → troubleshooting → DevOps labs.
